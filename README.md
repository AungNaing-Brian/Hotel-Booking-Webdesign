# 🏨 Hotel Booking Website

A modern and responsive hotel booking website designed to showcase hotel rooms, prices, and booking options in a clean and inviting layout. This project demonstrates key web design and frontend development skills, making it great for web portfolios or practice.

🔗 **Live Demo:** https://hotel-booking-webdesign.netlify.app/

---

## ✨ Features

- Responsive hotel landing page
- Hero section with property introduction
- Room listings with sizes, capacity, and prices
- “Book Now” call-to-action buttons
- Clean and user-friendly UI
- Structured content showcasing hotel offerings

---

## 🛠️ Technologies Used

This project is built using:

- **HTML5**
- **CSS3**
- **JavaScript**
